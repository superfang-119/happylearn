# 快乐学 · 拾光群岛

面向七年级上学期的中文像素冒险游戏。学生带着精灵阿芽穿过四座岛，观察场景，收集记忆碎片，在新的情境里把同一条知识再用一次。

## 开始游戏

直接用现代浏览器打开 `dist/index.html` 即可开始。手机可以访问部署好的网址。所有关卡、图片和游戏逻辑都在项目里，无需账号或后端。桌面可用方向键移动，触屏可划动场景，也可直接点发光的线索。英语线索支持按需朗读，可用声音取决于浏览器和设备。

需要本地服务器时运行以下命令，然后访问 `http://localhost:8000`。

```sh
python -m http.server 8000 --directory dist
```

## 岛屿与任务

| 区域 | 学科 | 代表任务 |
| --- | --- | --- |
| 晨曦森林 | 英语 | 听问候语、追踪有色脚印、根据方位词找信包 |
| 蔚蓝港湾 | 地理 | 用罗盘找码头、通过比例尺备水、从等高线选缓坡 |
| 时光遗迹 | 历史 | 给河姆渡稻谷找家、拼合甲骨、跟随张骞西行 |
| 星月书院 | 语文 | 听雨辨感官、选择贴切的动词、给句子安排停顿 |

每岛 6 个任务。每座岛各完成任意一关，就能解锁 3 个跨科远征。每关有两个现场线索和一道换情境复习题。提示、重试和重玩都不扣分。进度保存在当前浏览器和设备中。内容取自七年级上常见入门知识点，未按某一地区教材逐课编排。

## 修改与验证

- `dist/content.js` 保存任务、线索、提示和复习题。
- `dist/game.js` 管理探索、移动、知识卡、奖励与本地存档。
- `dist/hub.js` 管理大厅入口与进度显示，`dist/voice.js` 提供英语朗读。
- `dist/art/` 包含本地像素场景和角色。

运行回归测试需要 Node.js 20 或更新版本。

```sh
node --test tests/*.cjs
```

生成可单独发给学生的离线网页，只需 Python 3。

```sh
python tools/export_offline.py happylearn-offline.html
```
