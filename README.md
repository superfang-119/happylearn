# 快乐学 · 英语闯关与听音背词

打开网页从英语第一关开始，也可以点「单词练习」从小学词汇补起。每个知识点都有中文线索、情境题和独立回想题。地理、历史、语文可随时切换。想探索时可以从学习页进入日落港或拾光群岛。

## 开始游戏

直接用现代浏览器打开 `dist/index.html` 即可开始。手机可以访问部署好的网址。单文件离线版可以直接在浏览器中打开。学习页支持鼠标、触屏和键盘，进度保存在当前设备的浏览器里。

需要本地服务器时运行以下命令，然后访问 `http://localhost:8000`。

```sh
python -m http.server 8000 --directory dist
```

## 零基础听音背词

「小学起步」和「初中衔接」各有 60 词，按教室、家庭、出行、校园生活等主题编排。两档表示练习难度。选词参考教育部《义务教育英语课程标准（2022年版）》附录词汇表。课标三级词表共 1,600 词，其中包括 505 个二级词汇，本版选取 120 词作起步练习。[教育部课标原文](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582349487953.pdf)

每组 3 个词。点「单词练习」开始，也可以在「查词库」选词。120 词都有整词美音、音标和拼写提示，42 词可以从第一个字母一直拆到词尾。以 **bike** 为例，一组里的练法如下。

| 小游戏 | 学生怎么做 |
| --- | --- |
| 听辨 | 看过词卡后点「听音闯关」，拼写随即收起。听整词，再试听 A、B 两个元音，选出 /aɪ/。可以重听或看口形提示。 |
| 拼读 | 听 /b/、/aɪ/、/k/，依次点 **b、i、k**，最后补上不单独发音的 **e**。拼完可连听分音和整词。点错可以原地再选。 |
| 独立拼写 | 换过其他词卡后，只看「自行车」自己写出英文。可打字或点完整键盘。用了首字母、备选字母或揭晓，就隔一张卡再试。 |
| 换情境回想 | 过一张别的卡，再根据修车的场景填 *The chain on my ___ is loose.* 独立拼对才结算，每词每天 3 经验、2 金币。 |

到期词优先直接做情境回想，连续独立答对的复习间隔是 1、3、7、14 天。以下 30 词各有两条不同的挖空句，独立完成后下次换题。答错不会扣经验或金币。刷新和切换学段会保留已拼到的字母块。

| 这次新增的拼读难点 | 单词 |
| --- | --- |
| 短元音与短词 | egg、bus、run、ask、help、west |
| 辅音组合与收尾 | clock、sing、drink、school |
| 同一种拼写的不同读音、不同拼写的相同读音 | room、eat、read、speak、bread、sleep、friend |
| 滑动元音 | play、rain、count、right |
| 词尾静音 e | home、bike、late、safe |
| 美式 r 音与多音节词 | park、pencil、mother、father、sister |

选词兼顾日常使用频率和可演示的拼读现象。以上 30 词在 2018 英语影视字幕词频表中均排在前 6,000，具体到书写工具的 pencil 排第 5,821。[选词词频表](https://github.com/hermitdave/FrequencyWords/blob/525f9b560de45753a5ea01069454e72e9aa541c6/content/2018/en/en_50k.txt)

整词和分音使用内嵌的 Flite US SLT 美式合成录音，例句朗读取决于设备的英语语音。项目使用宽式美音音标，省略元音长度符号，例如原形 read /rid/、bread /brɛd/。每个新增词均按其词义核对重读元音和整条音素序列。开发者可用 Node.js、Python、Flite 和 FFmpeg 在 Linux 上运行 `python3 tools/build_word_audio.py` 重新生成录音。[CMUdict 核对版本](https://github.com/cmusphinx/cmudict/blob/74790861f652b15e4ac49015a90074ad62a27690/cmudict.dict) · [Cambridge 的 read 原形与过去式](https://dictionary.cambridge.org/pronunciation/english/read)

### 扩展到课标词汇

1. 仓库以 2022 年版为起点，三级 1,600 词已包含二级的 505 词。全量扩充前，将既有 120 词与 2025 年日常修订版附录逐项对照，记录版本、层级、词义、英美拼写和增删调整，保留旧存档词键。先补二级基础词，再按七至九年级主题分批。[2022 年版，第 98 页](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582349487953.pdf) · [2025 年日常修订版](https://fxzx.qpedu.cn/jhzx/kcjs/kcbz/511602.htm)
2. 每批在 `dist/vocab-data.js` 配中文义、例句及两条不同情境的挖空题。在 `dist/vocab-ipa.js` 标美式 IPA、重音和有序字母块。先按具体词义从词典挑选读法，再人工划分拼写边界。音素词典不能替代这一步。词尾静音保留为 ∅，一组字母也可共表一个音。对于同形异音词，给不同义项独立的题目和音频映射。
3. 先跑拼写复原、音素复原、独立录音覆盖和三词流程测试，再用离线页面试听。引入新的重读元音时，在 `dist/phonics-drill.js` 配好可比较的声音和口形提示，给新增音素生成音轨。有多个可能读法的词按课内例句复核后再开放完整拆音。

## 按知识点闯关

新玩家从英语第一关开始。点学科名，就能看到该科的知识点清单、已通过的关卡和下一关，也能切换为四科轮练。单科按清单顺序解锁，已经通过的点可以重练。每轮最多三个知识点。答错可以立即重试，借助提示或灵感卡后，还会换个例子请你独立作答。刷新或从城市回来，可以继续原来的练习。

| 学科 | 各阶段知识点（按过关顺序） |
| --- | --- |
| 英语 1–6 · 生活表达 | 介绍名字、颜色词、用介词说位置、家庭成员、用 There is / are 说数量、介绍最喜欢的学科 |
| 英语 7–12 · 句子基础 | am / is / are、形容词性物主代词、a / an、指示代词、名词复数、be 动词问句与简答 |
| 英语 13–18 · 校园日常 | 礼貌问候、can / can’t、第三人称单数、do / does 问喜好、星期和 on、钟点和 at |
| 地理 | 指北箭头、比例尺、经纬度、等高线、地球自转与昼夜、天气和气候 |
| 历史 | 河姆渡、半坡、甲骨文、铁农具与牛耕、秦统一文字、丝绸之路上的交流 |
| 语文 | 感官描写、比喻、拟人、选动词、尊君与家君、朗读停顿 |

英语普通题可听双语卡上的英语范句；答对后可以点词块把句子拼回来。页头的「勋章」共八枚。四科原有的基础勋章按最初六关计数，英语全 18 关另解锁「英语全程领航」。

点「换装」可试穿四套造型。见习探险家开局可穿，通过第一关解锁晨光信使，四科各过一关解锁绿野巡游者，完成任意一科的前六关解锁星图领航员。换上的服装会显示在学习页，日落港里步行和开车的人物也会换上对应配色。

## 日落港开放世界

选择城市探索后，可用 WASD 或方向键移动、Shift 奔跑、E 上下车或互动。拖动画面环视，M 打开地图。手机有屏幕方向键。点「回去学习」可继续答题。

- **委托手机**可接英语邮递、地理测绘、历史布展、语文采风四份委托。把车开到地图上的地点，读路牌、辨方向、找展品、收诗句。完成四份委托后开启跨科环城接力。
- **自由驾驶**可收集地标印记、选择电台、为敞篷车更换解锁的车漆。海岸试车从第一局开放，经过起点才计时，手机菜单和后台会暂停计时。
- **技术**使用本地分发的 Three.js r159、原生 JavaScript 和 Web Audio。静态场景按实例批量绘制。缺少 WebGL 时使用 Canvas 软件绘制的第三人称街景。依赖许可证在 `dist/vendor/THREE-LICENSE.txt`。
- 委托按站点保存，个人圈速、知识卡、已解锁车漆和地标印记也保存在当前浏览器。答题钱包与群岛共用，委托、圈速及地标进度另行保存。

## 答题、升级与道具

学习首页选对答案即可领奖；日落港也有「答题赚币」入口。也可以在一份学科委托完成后就地答该科的题。每累计 80 经验升一级，买道具只花金币。

| 获奖条件 | 经验 | 金币 |
| --- | ---: | ---: |
| 学习页或城市首次答对某题，每题每天领一次 | 15 | 10 |
| 普通岛屿任务首次通关 | 20 | 12 |
| 跨科远征首次通关 | 40 | 24 |
| 到期知识卡复习答对 | 8 | 5 |
| 拼对英语目标词，每词每天首次独立拼对 | 3 | 2 |

第一次答对就买得起 8 金币的灵感卡。答题时使用一张可排除一个错误选项。32 金币的跑鞋可让步行、奔跑提速 35%，48 金币可以买霓虹玫红车漆。跑鞋和车漆买后可在背包反复穿戴或卸下。答错、看提示或重试都不会扣钱。已有玩家会按已完成的岛屿任务自动补领金币。

## 岛屿与任务

| 区域 | 学科 | 代表任务 |
| --- | --- | --- |
| 晨曦森林 | 英语 | 听问候语、追踪有色脚印、根据方位词找信包 |
| 蔚蓝港湾 | 地理 | 用罗盘找码头、通过比例尺备水、从等高线选缓坡 |
| 时光遗迹 | 历史 | 给河姆渡稻谷找家、拼合甲骨、跟随张骞西行 |
| 星月书院 | 语文 | 听雨辨感官、选择贴切的动词、给句子安排停顿 |

英语岛 18 个任务，另外三座岛各 6 个任务。每座岛各完成任意一关，就能解锁 3 个跨科远征。每关有两个现场线索和一道换情境复习题。提示、重试和重玩都不扣分。进度保存在当前浏览器和设备中。内容取自七年级上常见入门知识点，未按某一地区教材逐课编排。

## 修改与验证

- `dist/content.js` 保存任务、线索、提示和复习题；`dist/learn-facts.js` 提供短讲解和换情境练习。
- `dist/learn-round.js` 管理轮练进度和复练安排，`dist/learn.js` 展示学习首页。
- `dist/game.js` 管理探索、移动、知识卡、奖励与本地存档。
- `dist/hub.js` 管理大厅入口与进度显示，`dist/voice.js` 提供英语朗读。
- `dist/art/` 包含本地像素场景和角色。

运行回归测试需要 Node.js 20 或更新版本。

```sh
node --test tests/*.test.cjs
```

生成可单独发给学生的离线网页，只需 Python 3。

